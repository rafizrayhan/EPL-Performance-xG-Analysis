# EPL Performance vs Expected Goals (xG) Analysis

## Question
Which EPL teams overperformed or underperformed across attacking, defensive, and overall performance metrics?

## Data
EPL season statistics sourced from Understat via Kaggle.
20 teams · 12 variables including goals, xG, xGA, points, and xPTS.

## Methodology
Three separate analyses conducted:
1. Attacking — Goals Scored vs Expected Goals (xG)
2. Defensive — Expected Goals Against (xGA) vs Goals Conceded
3. Overall — Actual Points vs Expected Points (xPTS)

Each metric visualised as a horizontal bar chart coloured by over/underperformance.

## Key Findings

**Attacking:**
- Crystal Palace were the biggest underperformers (-21.5 goals vs xG)
- Tottenham were the biggest overperformers (+1.2 goals vs xG)

**Defensive:**
- Nottingham Forest conceded 13.7 fewer goals than xGA suggested
- Tottenham conceded 1.4 more goals than expected

**Overall Points:**
- Aston Villa earned 13.9 more points than xPTS predicted
- Wolverhampton underperformed by 15.4 points vs xPTS
